# رابط دوم مووی لایت — نسخه سینمایی

این بسته، سورس کامل همان نسخه نمایشی منتشرشده با الهام از Netflix و Apple TV است؛ با برند Muvi Lite، زبان فارسی، چیدمان راست‌به‌چپ و فونت یکان‌بخ.

## اجرای محلی در ویندوز

۱. Node.js نسخه ۲۰ یا جدیدتر را نصب کنید.
۲. فایل ZIP را استخراج کنید و در پوشه MUVI_LITE_UI_2 ترمینال یا PowerShell باز کنید.
۳. دستورهای زیر را به ترتیب اجرا کنید:

```sh
npm ci
npm run dev
```

آدرس محلی نمایش‌داده‌شده در ترمینال را در مرورگر باز کنید.

## خروجی قابل استقرار

نسخه ساخته‌شده داخل پوشه dist قرار دارد. برای ساخت مجدد:

```sh
npm run build
```

برای مشاهده خروجی ساخته‌شده از طریق وب‌سرور محلی:

```sh
npm run preview
```

فایل index.html را مستقیم با دوبار کلیک باز نکنید؛ برنامه باید با وب‌سرور اجرا شود. برای استقرار مستقل، محتوای dist را در ریشه وب‌سایت میزبان قرار دهید.

## فایل‌های اصلی

- src/App.jsx: صفحه‌ها و اجزای رابط
- src/style.css: طراحی ظاهری و واکنش‌گرایی
- src/data.js: کاتالوگ و محتوای نمونه
- public/assets: تصاویر، فونت‌ها، لوگو و ویدئوی نمونه
- README.md: توضیحات فنی و مسیر پیشنهادی اتصال به پروژه اصلی

## محدوده نسخه

این نسخه نمونه تعاملی رابط کاربری است و به بک‌اند اصلی Muvi Lite متصل نیست. فیلم‌های کاتالوگ پخش نمی‌شوند؛ پخش‌کننده برای نمایش عملکرد، تریلر نمونه Sintel را پخش می‌کند و این موضوع در صفحه پخش مشخص شده است. علاقه‌مندی‌ها و پیشرفت تماشا فقط روی مرورگر همان دستگاه ذخیره می‌شوند.

برای استفاده در محصول اصلی می‌توان این سورس را به‌عنوان پوشه UI/2 نگهداری و سپس آن را به API، پخش‌کننده اختصاصی Muvi و سازوکار تبلیغات و رهگیری پروژه اصلی متصل کرد.

تصاویر فیلم‌ها برای نمایش طراحی استفاده شده‌اند؛ برای بهره‌برداری عملیاتی، تصاویر محتوای دارای مجوز جایگزین شوند. حقوق لوگو و فونت تابع شرایط صاحبان آن‌هاست. مجوز کد و منابع ویدئوی نمونه در LICENSE و README.md آمده است.
